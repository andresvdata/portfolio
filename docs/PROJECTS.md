# Selected projects and why

Five featured case studies, plus compact rows for smaller work. Each case study was chosen for evidence, relevance to the target roles, variety and what can be shown publicly.

## Featured case studies

| # | Case study | Type | What it proves | Public evidence |
| --- | --- | --- | --- | --- |
| 1 | **Turning 40+ scattered sources into one reporting foundation at BC SPCA** | Professional | Current stack (Microsoft Fabric, Power BI, DAX), data integration at scale, KPI governance, stakeholder partnership. The strongest and most recent proof for BI Developer roles. | None yet. The data is operational. See Questions for Andres. |
| 2 | **One secure workspace for research data, from lab notebook to dashboard (Langara)** | Professional | Data engineering: Docker, Airflow, Azure, Postgres, Superset, single sign-on. Shows I can run infrastructure, not only dashboards. | Public repository README (architecture and user flow). |
| 3 | **Predicting patient lifetime value, a probability model against machine learning** | Academic / research | Statistical and ML modeling for healthcare stakeholders, ending in a peer-reviewed paper (co-author). | The paper (DOI). |
| 4 | **From manual processing to an automated BI stack at Softgic** | Professional | The classic Microsoft BI stack end to end (SSIS, Pentaho, snowflake schema, SSAS, SSRS, Power BI) with about 60% less processing time. | Blurred dashboard samples and an SSIS data flow from the earlier portfolio. |
| 5 | **SmartEnerx, forecasting London household energy demand** | Academic / research (team) | Forecasting and a deployed Dash app: Prophet at about 1.36% MAPE against two alternatives. | Public repository, report PDFs, YouTube demo, datafolio poster, forecast chart. |

Order on the page runs from most current (BC SPCA) to oldest, so a recruiter sees the strongest, most recent evidence first. Change the order with the `order` number in each file.
